# MCP 与独立 API Key 联调记录

验证日期：2026-09-23。

后端由 Codex 实现；登录、密钥管理和连接配置页面由 Grok CLI 实现。

## 实现范围

- 官方 MCP Python SDK 的 Streamable HTTP `/mcp` 接口，六个只读工具。
- 管理员登录后签发独立随机 Key；读取权限必需，可选 REST 分析权限及到期时间。
- 数据库存储 Key 摘要；完整 Key 仅创建时返回，支持撤销和最后使用时间。
- 物料接口、导出、MCP 与凭据管理均鉴权；管理员会话不充当 MCP Key。
- 所有 Key 访问同一项目数据；没有租户隔离，也不提供 OAuth 授权服务器。

## 验证结果

后端 57 项自动化测试通过，覆盖既有库存分析、独立 Key、权限、到期、撤销、管理员会话、来源校验、登录限流、官方 MCP 客户端和证据查询。

浏览器连接真实后端，使用隔离的临时凭据目录完成：

| 场景 | 结果 |
| --- | --- |
| 管理员登录、进入密钥页面、创建只读 Key | 成功 |
| 页面生成的 Key 初始化 MCP、列出工具 | HTTP 200，六个工具 |
| MCP 查询真实 ERP 分析任务 | 12,794 条有效流水、820 个物料、180 天候选 13 个 |
| 只读 Key 上传分析 | HTTP 403 |
| 页面撤销 Key 后再次调用 MCP | HTTP 401 |
| 关闭完整 Key 显示 | 页面不再提供完整值 |
| 浏览器持久化检查 | localStorage / sessionStorage 均为空 |
| 退出后请求物料接口 | HTTP 401；页面隐藏物料与密钥管理 |
| localhost 与 127.0.0.1 两种本地访问 | 均可登录；开发 API 与页面主机名保持一致 |

Grok 完成前端生产构建验证，`npm run build` 通过。

测试凭据与项目正式凭据隔离，联调结束后关闭临时后端并恢复本机自动生成的管理员凭据。正式凭据不写入报告或源码。登录和连接步骤见 README。
