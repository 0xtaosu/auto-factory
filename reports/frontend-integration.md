# 物料活跃度 MVP 前端联调记录

日期：2026-09-23。前端由 Grok 实现，主代理执行浏览器验收。
使用真实 ERP 文件和本机 FastAPI 服务，没有用模拟结果替代业务数据。

| 检查 | 结果 |
|---|---|
| 默认配置 | 2025-12-31，阈值 180 天 |
| 真实 Excel 上传 | 12,794 个有效事件、820 个物料、13 个候选 |
| 阈值覆盖为 90 天 | 73 个候选，策略快照为 slow-moving-custom-90d |
| 分页 | 820 条，50 条/页，共 17 页；下一页可用 |
| 候选筛选 | 180 天返回 13 条；90 天返回 73 条 |
| 搜索 GC010 | 末次日期 2025-12-08，23 天，未达阈值 |
| 不存在的物料搜索 | 0 条，显示空结果说明 |
| BZ118 追溯 | 342 天，末次日期 2025-01-23，可定位 Excel 第 12184 行和源文件 SHA256 |
| 单位冲突 | 531 个物料总量不可用，保留分单位数量；BZ118 显示出库 121 件、入库 304 套 |
| 下载 | JSON、CSV、Turtle、Markdown 均触发浏览器下载且文件名正确 |
| 非法 Excel | 返回“无法读取 Excel 工作簿”，未显示零值概览 |
| 列表网络失败 | 人为阻断一次请求，旧数据隐藏，提供“重试当前查询” |
| 请求重试 | 恢复同一 GC010 查询并进入详情，返回 1 条 |
| 异步状态 | 分析请求期间“重新上传”禁用，避免旧请求回填 |
| 桌面显示 | 概览标题完整，策略说明换行，未截断 |
| 移动端 | 390×844，详情页无整页横向溢出，宽表在容器中滚动 |
| 运行时 | 稳定版本浏览器未发现 JavaScript pageerror；模拟失败请求产生预期网络错误 |
| 生产构建 | npm run build 成功，1696 个模块 |

浏览器验收过程中发现并由 Grok 修复了标题截断、列表请求失败保留旧结果、
重置请求竞态和 `.xls` 选择不受支持的问题。开发热更新过程中的临时重载不计为最终版本结果。

后端此前 47 项自动化测试通过。本轮未修改后端；未部署到远端。
数据质量边界仍见 `inventory-activity-mvp.md`：候选不能证明当前正库存；
单位冲突的年度总量需要业务主数据或换算依据，前端不自行补造。
