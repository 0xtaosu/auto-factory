## 三、卡片设计

### 3.1 L1概览卡片（4个指标）

每个卡片固定尺寸，水平均匀排列，内容包含：

```
┌─────────────────────────────┐
│  🔴 / 🟡 / 🟢              │  ← 左上角指示灯
│  库存总资金                  │  ← 指标名称（12px，灰色）
│                              │
│  2.8亿                       │  ← 核心数字（28px，加粗，白色）
│                              │
│  ↑ 较上月+8%  ↓ 一句话小字   │  ← 趋势/说明（12px）
│  「资金持续增长，需关注」     │
└─────────────────────────────┘
         │ 点击任意位置进入L2
         ▼
```

## 五、表达风格

| 场景 | 原文风格 | V2风格 |
|:-----|:---------|:-------|
| 整体结论 | "整体来看，全年库存呈现持续累积态势" | 「库存有点危险，建议开个会」 |
| 资金异常 | "库存资金达¥120.13亿，较1月增长822%" | 「库存2.8亿，月月涨，该管管」 |
| 呆滞偏高 | "呆滞物料662种，金额¥9.88亿" | 「死货占了12%，三千多万烂在仓库」 |
| 平衡失衡 | "进销比1.79:1，入库速度持续高于出库" | 「每月买多卖40%，钱只进不出」 |
| 无异常 | — | 「库存还行，继续看着」 |
| 正常 | — | 「没什么问题」 |

## 六、交互规范

| 交互 | 行为 |
|:-----|:------|
| 点击L1卡片 | 平滑过渡→L2详情页 |
| L2点击"←返回" | 回到L1概览 |
| 鼠标悬停卡片 | 轻微上浮阴影（transform: translateY(-2px)） |
| 鼠标悬停图表 | 显示数据提示（tooltip） |
| 页面加载 | 渐入动画（fade in 0.3s） |
| 数据加载中 | 骨架屏（灰色脉冲块） |

## 七、异动/错误状态

| 状态 | 表现 |
|:-----|:------|
| 数据不足（<30天） | 整页显示：「数据周期不足，无法分析」 |
| 文件解析失败 | 红色提示卡片：「文件格式不支持，请重试」 |
| 免费次数用尽 | 弹出支付页：「免费次数已用完」 |
| 服务器异常 | 友好提示：「系统繁忙，请稍后再试」 |
