## ALG-001：库存总资金及月度趋势

### 定义

| 项目 | 内容 |
|:----|:-----|
| 指标名 | 库存总资金及月度趋势 |
| 数据来源字段 | `trans_date`, `trans_type`, `amount` |
| 依赖配置 | `report_start_date`（分析起始日期，默认取数据中最早日期） |
| 输出 | 当前库存总资金 + 月度趋势（最近12个月） + 趋势方向判断 |

### 算法伪代码

```
FUNCTION calc_inventory_value(transactions, config):
    // 入参: transactions = List[Transaction], config = Config
    // 出参: {total_value, monthly_trend[], trend_direction}

    // Step 1: 按时间排序
    sorted_tx = transactions.sort_by(trans_date)

    // Step 2: 计算总库存
    //   注意：不含期初结存，报告顶部标注"基于交易数据"
    total_in = sum(tx.amount FOR tx IN sorted_tx WHERE tx.trans_type == "入库")
    total_out = sum(tx.amount FOR tx IN sorted_tx WHERE tx.trans_type == "出库")
    total_value = total_in - total_out
    
    // Step 3: 按月计算净增
    //   按月分组: 入库金额 - 出库金额
    monthly_raw = {}
    FOR tx IN sorted_tx:
        month_key = tx.trans_date.strftime("%Y-%m")
        IF tx.trans_type == "入库":
            monthly_raw[month_key].in += tx.amount
        ELSE:
            monthly_raw[month_key].out += tx.amount
    
    monthly_trend = []
    FOR month_key IN sorted(monthly_raw.keys()):
        net = monthly_raw[month_key].in - monthly_raw[month_key].out
        monthly_trend.append({
            "month": month_key,
            "in_amount": monthly_raw[month_key].in,
            "out_amount": monthly_raw[month_key].out,
            "net_change": net
        })

    // Step 4: 趋势方向判断
    //   取最近3个月的月均净增 vs 前3个月的月均净增
    last_3 = monthly_trend[-3:]    // 最近3个月
    prev_3 = monthly_trend[-6:-3]  // 前3个月
    
    avg_last_3 = avg(t.net_change FOR t IN last_3)
    avg_prev_3 = avg(t.net_change FOR t IN prev_3)
    
    IF avg_last_3 <= 0:
        trend = "下降"     // 🟢
    ELIF avg_last_3 > avg_prev_3 * 1.1:
        trend = "快速上升" // 🔴
    ELIF avg_last_3 > avg_prev_3:
        trend = "缓慢上升" // 🟡
    ELSE:
        trend = "平稳"     // 🟢

    RETURN {
        total_value: total_value,
        monthly_trend: monthly_trend,
        trend_direction: trend
    }
```

### 边界条件

| 场景 | 处理方式 |
|:-----|:---------|
| 只有入库没有出库 | total_value = 所有入库金额之和，报告标注"仅有入库数据" |
| 入库<出库（负库存） | 按实际计算，报告正常显示，不强制归零 |
| 数据不足3个月 | trend_direction = "数据不足"，不显示趋势箭头 |
| 某个月没有交易数据 | monthly_trend中该月net_change=0，缺失月不补 |

## ALG-002：呆滞/慢动物料占比

### 定义

| 项目 | 内容 |
|:----|:-----|
| 指标名 | 呆滞/慢动物料占比 |
| 数据来源字段 | `material_code`, `trans_date`, `trans_type`, `amount` |
| 依赖配置 | `stagnant_days`（呆滞天数，默认180天，可配置范围30~720） |
| 输出 | 呆滞占比 + 呆滞金额 + 呆滞物料TOP清单 |

### 算法伪代码

```
FUNCTION calc_stagnant_ratio(transactions, config):
    // 入参: transactions, config (内含 stagent_days)
    // 出参: {ratio, amount, top_list[], analysis_date}

    // Step 1: 确定分析基准日
    //   基准日 = 数据中最后一条交易日期
    base_date = max(tx.trans_date FOR tx IN transactions)
    
    // Step 2: 找每个物料的最后出库日
    //   按物料编码分组，取最后一条出库记录的日期
    out_transactions = FOR tx IN transactions WHERE tx.trans_type == "出库"
    
    material_last_out = {}
    FOR tx IN out_transactions:
        code = tx.material_code
        IF code NOT IN material_last_out OR tx.trans_date > material_last_out[code].date:
            material_last_out[code] = {
                "date": tx.trans_date,
                "name": tx.material_name,
                "spec": tx.material_spec
            }

    // Step 3: 计算每个物料的呆滞状态和占用资金
    //   物料资金 = 该物料的所有入库金额之和 - 所有出库金额之和
    material_amount = {}
    FOR tx IN transactions:
        code = tx.material_code
        IF code NOT IN material_amount:
            material_amount[code] = 0
        IF tx.trans_type == "入库":
            material_amount[code] += tx.amount
        ELSE:
            material_amount[code] -= tx.amount

    // Step 4: 标记呆滞物料
    stagnant_list = []
    total_stagnant_amount = 0
    total_amount = 0
    
    FOR code, amount IN material_amount:
        total_amount += amount
        IF code IN material_last_out:
            last_date = material_last_out[code].date
            days_since = (base_date - last_date).days
            // 注意：天数计算精确到天，不按日历日取整
            IF days_since >= config.stagnant_days:
                total_stagnant_amount += amount
                stagnant_list.append({
                    "material_code": code,
                    "material_name": material_last_out[code].name,
                    "material_spec": material_last_out[code].spec,
                    "last_out_date": last_date,
                    "days_since_last_out": days_since,
                    "current_amount": amount
                })
        ELSE:
            // 只有入库没有出库 → 标记为"疑似呆滞"，计入呆滞
            total_stagnant_amount += amount
            stagnant_list.append({
                "material_code": code,
                "material_name": material_amount_meta[code].name,
                "material_spec": material_amount_meta[code].spec,
                "last_out_date": null,
                "days_since_last_out": null,
                "current_amount": amount,
                "flag": "only_inbound_no_outbound"
            })

    // Step 5: 计算占比
    IF total_amount > 0:
        stagnant_ratio = total_stagnant_amount / total_amount
    ELSE:
        stagnant_ratio = 0
        stagnant_list = []

    // Step 6: 排序取TOP
    top_list = stagnant_list.sort_by("current_amount", desc).take(10)

    // 配置项校验
    IF config.stagnant_days < 30 OR config.stagnant_days > 720:
        RAISE ConfigError("stagnant_days must be between 30 and 720")

    RETURN {
        stagnant_ratio: round(stagnant_ratio, 4),
        stagnant_amount: round(total_stagnant_amount, 2),
        stagnant_count: len(stagnant_list),
        top_stagnant_list: top_list,
        config_days: config.stagnant_days,
        analysis_date: base_date
    }
```

### 边界条件

| 场景 | 处理方式 |
|:-----|:---------|
| 数据周期 < config.stagnant_days | 不计算指标，报告标注"数据周期不足" |
| 所有物料都有出库记录 | stagnant_ratio = 0，绿灯 |
| total_amount = 0（入库=出库完全平衡） | stagnant_ratio = 0，但标注"库存净值为0" |
| 物料只有入库没有出库 | 标记为"疑似呆滞"，计入呆滞，备注无出库记录 |

## ALG-003：月度出入库平衡度

### 定义

| 项目 | 内容 |
|:----|:-----|
| 指标名 | 月度出入库平衡度 |
| 数据来源字段 | `trans_date`, `trans_type`, `amount` |
| 依赖配置 | 无 |
| 输出 | 最近12个月的月度出入比 + 整体判断 |

### 算法伪代码

```
FUNCTION calc_balance_ratio(transactions, config):
    // 入参: transactions
    // 出参: {monthly_ratios[], overall_ratio, judgment}

    // Step 1: 按月统计入库和出库金额
    monthly = {}
    FOR tx IN transactions:
        month_key = tx.trans_date.strftime("%Y-%m")
        IF month_key NOT IN monthly:
            monthly[month_key] = {"in": 0, "out": 0}
        IF tx.trans_type == "入库":
            monthly[month_key].in += tx.amount
        ELSE:
            monthly[month_key].out += tx.amount

    // Step 2: 计算每个月的出入比
    //   出入比 = 入库金额 / 出库金额
    //   注意：出库为0时，比值为无穷大，标记为null并特殊处理
    monthly_ratios = []
    FOR month_key IN sorted(monthly.keys()):
        m = monthly[month_key]
        IF m.out > 0:
            ratio = m.in / m.out
        ELSE:
            ratio = null  // 出库为0，无法计算比值
        
        monthly_ratios.append({
            "month": month_key,
            "in_amount": m.in,
            "out_amount": m.out,
            "ratio": ratio
        })

    // Step 3: 整体判断（最近6个月的平均出入比）
    last_6 = monthly_ratios[-6:]
    valid_ratios = [m.ratio FOR m IN last_6 WHERE m.ratio IS NOT null]
    
    IF len(valid_ratios) == 0:
        overall_ratio = null
        judgment = "数据不足"
    ELSE:
        overall_ratio = avg(valid_ratios)
        
        IF overall_ratio <= 1.2 AND overall_ratio >= 0.8:
            judgment = "平衡"   // 🟢
        ELIF overall_ratio <= 1.5:
            judgment = "轻微失衡"  // 🟡
        ELSE:
            judgment = "严重失衡"  // 🔴

    RETURN {
        overall_ratio: round(overall_ratio, 2),
        judgment: judgment,
        monthly_ratios: monthly_ratios
    }
```

### 边界条件

| 场景 | 处理方式 |
|:-----|:---------|
| 某月出库为0 | ratio = null，该月跳过，标注"该月无出库记录" |
| 入库<出库 | 出入比<1，正常计算，不强制归1 |
| 只有1个月数据 | overall_ratio = 该月比值，judgment = "数据不足，仅供参考" |
| 所有月份入库=出库 | 出入比=1，完美平衡 🟢 |

## ALG-004：异常物料检测

### 定义

| 项目 | 内容 |
|:----|:-----|
| 指标名 | 异常物料检测 |
| 数据来源字段 | `material_code`, `material_name`, `material_spec`, `trans_date`, `trans_type`, `quantity`, `amount` |
| 依赖配置 | `price_deviation_threshold`（单价偏离阈值，默认0.5即50%）<br>`qty_deviation_threshold`（数量偏离阈值，默认1.0即100%）<br>`min_history_records`（最少历史记录数，默认3次） |
| 输出 | 各类异常数 + TOP异常物料清单 |

### 算法伪代码

```
FUNCTION detect_anomalies(transactions, config):
    // 入参: transactions, config
    // 出参: {anomaly_types[], total_anomalies, top_anomaly_list[]}

    // 只分析入库记录（采购相关）
    in_transactions = FOR tx IN transactions WHERE tx.trans_type == "入库"
    
    // 按物料编码分组
    material_tx = group_by(in_transactions, "material_code")

    anomalies = []

    // === 检测类型1: 单价突变 ===
    FOR code, tx_list IN material_tx:
        IF len(tx_list) < config.min_history_records:
            CONTINUE  // 历史记录不足，跳过
        
        // 按日期排序
        sorted_list = tx_list.sort_by("trans_date")
        
        // 计算历史平均单价（前N-1次的加权平均）
        history = sorted_list[0:-1]  // 除最后一次外
        total_qty = sum(h.quantity FOR h IN history)
        total_amt = sum(h.amount FOR h IN history)
        
        IF total_qty == 0:
            CONTINUE
        
        avg_price = total_amt / total_qty
        
        // 最近一次的单价
        last_tx = sorted_list[-1]
        last_price = last_tx.amount / last_tx.quantity IF last_tx.quantity > 0 ELSE 0
        
        // 计算偏离度
        IF avg_price > 0:
            deviation = abs(last_price - avg_price) / avg_price
        ELSE:
            deviation = 0
        
        IF deviation >= config.price_deviation_threshold:
            direction = "上涨" IF last_price > avg_price ELSE "下跌"
            anomalies.append({
                "material_code": code,
                "material_name": last_tx.material_name,
                "material_spec": last_tx.material_spec,
                "anomaly_type": "price_spike",
                "anomaly_desc": f"采购单价{direction}，偏离{deviation*100:.0f}%",
                "last_price": last_price,
                "avg_price": round(avg_price, 2),
                "deviation_ratio": round(deviation, 4),
                "last_amount": last_tx.amount
            })

    // === 检测类型2: 采购量突变 ===
    FOR code, tx_list IN material_tx:
        IF len(tx_list) < config.min_history_records:
            CONTINUE
        
        sorted_list = tx_list.sort_by("trans_date")
        history = sorted_list[0:-1]
        
        avg_qty = avg(h.quantity FOR h IN history)
        last_qty = sorted_list[-1].quantity
        
        IF avg_qty > 0:
            deviation = abs(last_qty - avg_qty) / avg_qty
        ELSE:
            deviation = 0
        
        IF deviation >= config.qty_deviation_threshold:
            anomalies.append({
                "material_code": code,
                "material_name": sorted_list[-1].material_name,
                "material_spec": sorted_list[-1].material_spec,
                "anomaly_type": "qty_spike",
                "anomaly_desc": f"采购量异常，变化{deviation*100:.0f}%",
                "last_quantity": last_qty,
                "avg_quantity": round(avg_qty, 2),
                "deviation_ratio": round(deviation, 4),
                "last_amount": sorted_list[-1].amount
            })

    // === 检测类型3: 长期不出库（有入库无出库或出库极少） ===
    // 需要同时看出库记录
    out_transactions = FOR tx IN transactions WHERE tx.trans_type == "出库"
    material_out_count = count_by(out_transactions, "material_code")
    
    FOR code, tx_list IN material_tx:
        IF len(tx_list) < config.min_history_records:
            CONTINUE
        out_count = material_out_count.get(code, 0)
        IF out_count <= 1:
            anomalies.append({
                "material_code": code,
                "material_name": tx_list[0].material_name,
                "material_spec": tx_list[0].material_spec,
                "anomaly_type": "no_outbound",
                "anomaly_desc": f"有入库但出库{out_count}次，疑似已不再使用",
                "last_amount": sum(tx.amount FOR tx IN tx_list)
            })

    // === 检测类型4: 采购频率异常 ===
    FOR code, tx_list IN material_tx:
        IF len(tx_list) < config.min_history_records * 2:
            CONTINUE  // 采购频率检测需要更多数据
        
        sorted_list = tx_list.sort_by("trans_date")
        
        // 将数据按时间分成前一半和后一半
        mid = len(sorted_list) // 2
        first_half = sorted_list[:mid]
        second_half = sorted_list[mid:]
        
        // 计算单位时间内的采购次数
        first_days = (first_half[-1].trans_date - first_half[0].trans_date).days
        second_days = (second_half[-1].trans_date - second_half[0].trans_date).days
        
        first_freq = len(first_half) / max(first_days, 1)
        second_freq = len(second_half) / max(second_days, 1)
        
        IF first_freq > 0:
            freq_change = abs(second_freq - first_freq) / first_freq
        ELSE:
            freq_change = 0
        
        IF freq_change >= 1.0:
            anomalies.append({
                "material_code": code,
                "material_name": sorted_list[-1].material_name,
                "material_spec": sorted_list[-1].material_spec,
                "anomaly_type": "freq_change",
                "anomaly_desc": f"采购频率异常变化，期初vs期末变化{freq_change*100:.0f}%",
                "last_amount": sum(tx.amount FOR tx IN sorted_list[-3:])
            })

    // === 排序输出 ===
    // 按金额降序排列
    anomalies.sort_by("last_amount", desc)
    top_list = anomalies[:10]

    RETURN {
        total_anomalies: len(anomalies),
        anomaly_types: {
            "price_spike": count(a FOR a IN anomalies WHERE a.anomaly_type == "price_spike"),
            "qty_spike": count(a FOR a IN anomalies WHERE a.anomaly_type == "qty_spike"),
            "no_outbound": count(a FOR a IN anomalies WHERE a.anomaly_type == "no_outbound"),
            "freq_change": count(a FOR a IN anomalies WHERE a.anomaly_type == "freq_change")
        },
        top_anomaly_list: top_list,
        config: {
            "price_deviation_threshold": config.price_deviation_threshold,
            "qty_deviation_threshold": config.qty_deviation_threshold,
            "min_history_records": config.min_history_records
        }
    }
```

### 边界条件

| 场景 | 处理方式 |
|:-----|:---------|
| 物料历史记录不足 | 跳过该物料，不检测，不报异常 |
| 所有单价都相同 | deviation = 0，无异常 |
| 入库记录中有quantity=0 | 该条记录跳过，不参与均价计算 |
| total_anomalies = 0 | 无异常，显示绿色"一切正常" |

## 红黄绿灯判定汇总

| 指标 | 🟢 绿灯 | 🟡 黄灯 | 🔴 红灯 |
|:----|:--------|:--------|:--------|
| 库存总资金 | 平稳或下降 | 缓慢上升 | 快速上升（最近3月>前3月*1.1） |
| 呆滞物料占比 | <5% | 5%~15% | >15% |
| 出入库平衡 | 比值0.8~1.2 | 比值1.2~1.5 | 比值>1.5 |
| 异常物料 | 0种 | 1-5种 | >5种或涉及金额>总库存10% |
